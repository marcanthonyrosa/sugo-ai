# Sugo AI reference library

This directory keeps the durable brand profile in the repository so positioning,
voice, and design decisions remain available in every development environment.

## Authority and intended use

| Reference | Use |
| --- | --- |
| [`brand/BRAND_FOUNDATIONS.md`](brand/BRAND_FOUNDATIONS.md) | Audience, offer, differentiation, operating beliefs, personality, and design principles |
| [`brand/MESSAGING_AND_VOICE.md`](brand/MESSAGING_AND_VOICE.md) | Message hierarchy, voice rules, reusable copy, claims guidance, and channel adaptation |
| [`brand/SHARING_AND_DISCOVERY.md`](brand/SHARING_AND_DISCOVERY.md) | Canonical domain, search metadata, social cards, icons, and external launch checklist |
| [`brand/README.md`](brand/README.md) | Logo inventory and practical asset guidance |
| [`../design.md`](../design.md) | Current website design tokens and implementation rules |
| [`../COPY_BRIEF.md`](../COPY_BRIEF.md) | Historical brief used to produce the first site-page copy; not the active voice guide |

Use the two brand wiki documents for new positioning, messaging, and creative
work. Use the current application and `design.md` for website implementation
details. When the strategy changes, update the wiki deliberately so future work
starts from the new decision rather than reconstructing it from individual
assets.
